# Delinea PAM — Overview

Delinea's Privilege Access Manager (PAM / Privilege Manager) protects privileged accounts and credentials — local admin passwords, domain admin credentials, service accounts, application and database credentials, SSH keys, and API keys — by vaulting them, rotating them, and controlling how and when they're used. See [Privileged Accounts](privileged-accounts.md), [Password Rotation](password-rotation.md), [Policies](policies.md), and [Session Management](session-management.md) for the individual capabilities.

## Mobile app

Delinea also ships a mobile app that doubles as an authenticator and a viewer for shared files and secrets.
