# Data Patrol — Overview

DataPatrol is the vendor covered here for a single product: a screen watermarking solution used as an insider-threat deterrent.

## Screen Watermark solution

DataPatrol's **Screen Watermark** solution is a data-loss-prevention / insider-threat control that places a **visible watermark across a user's screen at the operating-system level**.

The watermark can display details such as:

- The logged-in username
- IP address
- Time
- Other metadata

The idea is deterrence and traceability: if a user photographs or screenshots sensitive data displayed on screen and it later leaks, the watermark makes it possible to trace the leak back to the specific user and session it came from.
