# Proofpoint — Targeted Attack Protection Dashboard

The TAP dashboard is where the results of URL Defense and Attachment Defense come together — it's the single place to see what advanced threats Proofpoint has detected and how effective the protection has been.

**Where:** `Email Protection` → `Targeted Attack Protection` → `Dashboard`

## Navigating the dashboard

- **Filters** — narrow down the results shown on the dashboard.
- **Save** — exports the same information currently visible on the dashboard.
- **Threat Name column** — indicates whether a detected threat is an isolated/individual instance or part of a broader campaign.
- **Threat type** — the dashboard also displays what type of threat was detected (e.g. malicious URL vs. malicious attachment).

## Reports

The **Reports** section gives a statistical overview of TAP's effectiveness. There are three reports available, and each can be:

- Selected individually for printing, or
- Downloaded as a **CSV** file.

## Search and tools

- **Search** — helps locate an individual campaign among detected threats.
- **Tools** — used together with the URL Defense service; specifically, it can translate a rewritten (Proofpoint-wrapped) link back to the original URL.
