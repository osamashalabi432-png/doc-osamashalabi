# Important Tools for Network Monitoring

Hardening isn't a one-time action — ongoing monitoring is what confirms hardened devices stay hardened and catches anomalies early. The following tools are commonly used for network monitoring:

| Tool | Usage Description |
|---|---|
| [Nagios](https://assets.nagios.com/downloads/nagioscore/docs/nagioscore/4/en/quickstart.html) | A popular open-source tool for monitoring systems, networks, and infrastructure. Provides real-time monitoring and alerting for various services and applications. |
| [SolarWinds Network Performance Monitor](https://documentation.solarwinds.com/en/success_center/npm/content/npm_installation_guide.htm) | A comprehensive network monitoring tool providing real-time visibility into network performance and availability. Includes network mapping, automated network discovery, and customizable dashboards. |
| [PRTG](https://www.paessler.com/manuals/prtg/installation) | An all-in-one network monitoring tool covering performance and availability monitoring. Includes real-time traffic analysis, custom dashboards, and customizable alerts. |
| [Zabbix](https://www.zabbix.com/download) | A powerful open-source network monitoring tool providing real-time performance and availability monitoring. Includes customizable dashboards, network mapping, and alerting. |
