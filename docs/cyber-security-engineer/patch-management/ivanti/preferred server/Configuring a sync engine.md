Sync engines are supported to run on Windows only. However, a sync engine can upload files for any platform to preferred servers, and Neurons agents of any platform can download from Preferred Servers. After configuring the preferred servers, configure sync engines to automatically manage the content in them.

**To configure a sync engine**

1.Navigate to Admin > Preferred Server Settings > Sync engine configurations.

2.Click Add configuration.  
It displays a new Add Configuration details page.

3.Enter the name of the sync engine configuration.

4.From the Preferred Server(s) drop-down list, select the preferred servers.

5.Click Add configuration.  
The new configuration displays in the Sync engine configurations > Sync engine configurations list with the preferred servers linked to the Configuration name.

Ivanti recommends using secure SMB protocols. See [Preferred Server security recommendations](https://help.ivanti.com/ht/help/en_US/CLOUD/vNow/preferred-server-security-recommendations.htm).
