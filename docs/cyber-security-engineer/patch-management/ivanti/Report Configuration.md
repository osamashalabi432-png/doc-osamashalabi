- go to Reports > create a new report

- you have 4 types of reports:
	- patch reports: which device is behind on patch أي أجهزة متأخرة بالتحديثات؟
	- device reports: which patches are missing the most across company  أي باتشات ناقصة على أكثر عدد من الأجهزة؟
	- vulnerability reports: which security risks do we have and where شو المخاطر الأمنية عنا، ووين موجودة؟
	- deployment history: what did we patch and did it work شو اللي نزّلناه، وهل نجح؟
