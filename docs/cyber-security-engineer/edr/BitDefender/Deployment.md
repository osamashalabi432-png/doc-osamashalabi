### Create Installation Package
1. first we go to Network > Installation Package > Create
![](../../../attachments/Pasted%20image%2020261014150210.png)

- inside the instalation packages options
![](../../../attachments/Pasted%20image%2020261014150546.png)

- let's take a closer look on the available modules and what each one of them do
![](../../../attachments/Pasted%20image%2020261014150509.png)
- Anti-malware: basic signature anti virus
- Advanced Threat Control: monitoring how programs behave while they run
- Advanced Anti-Exploit: protects programs from their own bug like browsers, PDF reader and Office
- Firewall: controls network traffic
- network protection:
	- control control: let's you block websites or categories
	- Anti-phishing: blocks phishing websites
	- web traffic: scans web pages and downloads for malware while browsing
	- network attack defense: detects attacks coming out from the network
- device control: let's you allow or block external devices like USB
- power user: Lets a local admin change Bitdefender settings directly on the computer, protected by a password
- EDR Sensor: Collects detailed information about what happens on the computer. This lets you investigate attacks in GravityZone


- then we have the scan mode:
![](../../../attachments/Pasted%20image%2020261015095908.png)
1. local scan: happens on the computer itself
2. hybrid scan: The computer keeps a light database. Part of the work is sent to Bitdefender’s cloud
3. central scan: The scanning is sent to a Security Server that you install in your own network or a special virtual machine
