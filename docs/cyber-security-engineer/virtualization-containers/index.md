# Virtualization & Containers

Hypervisors, container engines, and orchestration platforms — the technologies that let one physical host run many isolated workloads. This category covers the two main flavors of virtualization (full-machine virtualization via hypervisors, and OS-level virtualization via containers) plus the day-to-day tooling used to run, secure, and orchestrate them.

| Section | Description |
|---|---|
| [Concepts](concepts.md) | Why virtualization exists, Type 1 vs Type 2 hypervisors, and how containers differ from VMs. |
| [Docker](docker/index.md) | The container platform/engine used to build, run, and ship containerized applications. |
| [Podman](podman/index.md) | A container and pod management tool with a Docker-like CLI, including rootless pod support. |
| [Kubernetes](kubernetes/index.md) | The orchestration platform used to run and manage containers at scale. |
